Download

PostSonde 1.0.0 is the first release. Its files are on GitHub, with checksums and a signed build attestation for every file. You can also build PostSonde from source.

Download 1.0.0 Build it from source

Linux is where PostSonde is developed and tested. The macOS app and the Windows installers are installed and started on GitHub's runners for every release, but haven't been used on a real Mac or PC yet.

Build it from source

  1. Install Go 1.27, Node.js 26 with npm, and git. Then install the Wails CLI, at the version PostSonde uses:

    go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0

  2. On Linux, install a C compiler and the GTK 4 and WebKitGTK 6.0 headers. On macOS, install the Xcode Command Line Tools with xcode-select --install. Windows needs no C compiler.

    # Debian 13, Ubuntu 24.04 and later
sudo apt install gcc libc6-dev pkg-config libgtk-4-dev \
    libwebkitgtk-6.0-dev libx11-dev
# Fedora
sudo dnf install gcc pkgconf-pkg-config gtk4-devel \
    webkitgtk6.0-devel libX11-devel

  3. Get the source, check the toolchain, and build:

    git clone https://github.com/sorrelfox/postsonde.git
cd postsonde
make setup   # checks the tools, installs the frontend's npm packages
make check   # optional: the same checks CI runs
make build   # bin/postsonde for this system

  4. Start it, with or without a project folder to open:

    bin/postsonde
bin/postsonde ~/work/my-api

Each file of a release has a target of its own. All but the last run in Docker containers, so they need Docker but none of the GTK libraries, and they leave their files in dist/:

  • make linux: the .deb packages and the AppImages
  • make rpm: the Fedora RPMs (FEDORA=44, 45 or all picks the release)
  • make flatpak: the Flatpak bundle
  • make windows: the Windows installers
  • make sources: the source tarball
  • make macos: on a Mac, the universal app and its disk image

docs/building.md covers every target and the details for each system.

Checking a download

Each release lists the SHA-256 checksum of every file in SHA256SUMS. Every file but that one also has a build provenance attestation: a signed record that this repository's release workflow built it from the tagged commit. In the folder with your download, the first line checks the checksum, and the second, with the GitHub CLI, the attestation:

sha256sum -c --ignore-missing SHA256SUMS
gh attestation verify PostSonde-<version>-x86_64.AppImage --repo sorrelfox/postsonde

Installing on Linux

Install a .deb or an .rpm with apt or dnf, not dpkg -i or rpm -i, so that the GTK and WebKit libraries it needs come along:

# Ubuntu 24.04 and later, Debian 13 and later
sudo apt install ./postsonde_<version>_amd64.deb
# Ubuntu 22.04, Debian 12
sudo apt install ./postsonde-gtk3_<version>_amd64.deb
# Fedora 44; on Fedora 45, the fc45 file
sudo dnf install ./postsonde-<version>-1.fc44.x86_64.rpm

The GTK 3 package is for releases that don't have WebKitGTK 6.0; on later ones, take the GTK 4 package. Each Fedora release has its own RPM, built against its libraries.

The Flatpak runs on the GNOME 51 runtime, which flatpak fetches from Flathub if you don't have it yet:

flatpak install --user ./PostSonde-<version>-x86_64.flatpak
flatpak run io.github.sorrelfox.PostSonde

The AppImage is one file that runs without installing:

chmod +x PostSonde-<version>-x86_64.AppImage
./PostSonde-<version>-x86_64.AppImage

It brings its own GTK 3 and WebKit2GTK, so it runs on Ubuntu 22.04, Debian 12, Fedora 36 and anything newer. It needs FUSE, that is the fusermount or fusermount3 tool and /dev/fuse; where FUSE isn't available, start it with --appimage-extract-and-run. It doesn't add itself to your applications menu, but a tool such as Gear Lever or AppImageLauncher can do that.

First launch on macOS

Unless a release says otherwise, the app is signed ad hoc and not notarized by Apple, which needs a paid developer account, so macOS blocks it the first time you open it.

  1. Open the .dmg and drag PostSonde to Applications.
  2. Open PostSonde. When macOS says it can't verify the app, click Done.
  3. Open System Settings › Privacy & Security, scroll to Security, and click Open Anyway next to PostSonde. The button stays there for about an hour after the previous step.
  4. Confirm with your password. From then on, PostSonde opens normally.

If macOS says the app "is damaged", run this in Terminal and open it again:

xattr -dr com.apple.quarantine /Applications/PostSonde.app

These steps come back with each new version until PostSonde is notarized.

First launch on Windows

  1. Download the installer for your PC: -amd64-setup.exe for most PCs, -arm64-setup.exe for Windows on ARM. Settings › System › About › System type tells you which you have.
  2. Run it. The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click More info, then Run anyway.
  3. Click through the installer. It installs for your user only, needs no administrator rights and downloads nothing. PostSonde is in the Start menu afterwards.

PostSonde needs the Microsoft Edge WebView2 Runtime. Windows 11 includes it, and Windows 10 gets it with Edge updates. If it's missing, the installer tells you where to get it.

To update, run the installer of the new version. To remove PostSonde, use Settings › Apps › Installed apps.

What it needs

PostSonde draws its window with the web view your system already has, not a bundled browser engine. Two packages bring their own: the AppImage has GTK 3 and WebKit2GTK inside, and the Flatpak runs on the GNOME runtime, with GTK 4 and WebKitGTK 6.0.
